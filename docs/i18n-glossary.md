## Rules

1. Product message keys are stable; wording can evolve without changing the key.
2. Technical identifiers, API names, source quotations, module codes and user-authored names remain exact unless a reviewed display translation exists.
3. Avoid literal translations that imply diagnosis, grading, surveillance or guaranteed outcomes.
4. Sinhala/Tamil punctuation and spacing should be reviewed in the rendered UI, not only in JSON.
5. Any glossary change increments or accompanies the translation resource version when it changes runtime meaning.
